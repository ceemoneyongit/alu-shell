# Shell Processes and Signals

This project covers Linux processes, PIDs, and signals in Bash scripting.

## Scripts

- `0-what-is-my-pid` - Displays the script's own PID
- `1-list_your_processes` - Displays all running processes
- `2-show_your_bash_pid` - Displays lines containing the word bash
- `3-show_your_bash_pid_made_easy` - Displays PID and name of bash processes
- `4-to_infinity_and_beyond` - Displays "To infinity and beyond" indefinitely
- `5-dont_stop_me_now` - Stops the 4-to_infinity_and_beyond process using kill
- `6-stop_me_if_you_can` - Stops the 4-to_infinity_and_beyond process without kill/killall
- `7-highlander` - Displays "To infinity and beyond" and handles SIGTERM
- `67-stop_me_if_you_can` - Stops the 7-highlander process
- `8-beheaded_process` - Kills the 7-highlander process
- `10-process_and_pid_file` - Creates PID file and handles signals
- `manage_my_process` - Writes "I am alive!" to a file every 2 seconds
- `11-manage_my_process` - Init script to manage manage_my_process
