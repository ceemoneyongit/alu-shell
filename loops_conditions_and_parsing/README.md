# Shell Loops, Conditions and Parsing

This project covers Bash scripting with loops, conditions, and parsing techniques.

## Scripts

- `1-for_best_school` - Displays "Best School" 10 times using for loop
- `2-while_best_school` - Displays "Best School" 10 times using while loop
- `3-until_best_school` - Displays "Best School" 10 times using until loop
- `4-if_9_say_hi` - Displays "Best School" 10 times, prints "Hi" after 9th iteration
- `5-4_bad_luck_8_is_your_chance` - Loops 1-10 with special messages on 4th and 8th
- `6-superstitious_numbers` - Displays 1-20 with cultural superstitions on 4, 9, 17
- `7-clock` - Displays time for 12 hours and 59 minutes
- `8-for_ls` - Lists current directory files showing only part after first dash
- `9-to_file_or_not_to_file` - Gives information about the school file
- `10-fizzbuzz` - FizzBuzz from 1 to 100
- `11-read_and_cut` - Displays username, UID, and home directory from /etc/passwd
- `12-tell_the_story_of_passwd` - Tells a story based on /etc/passwd
- `13-lets_parse_apache_logs` - Parses Apache logs for IP and HTTP status
- `14-dig_the-data` - Groups and sorts Apache log data by IP and status code
